# 经济/取舍设计笔记（用模拟找洞）

> 综合公开的游戏数值/经济设计常识（如 Ian Schreiber《Game Balance Concepts》系列）整理的中文笔记，非原文照搬。
> 用途：设计赚钱模拟器的经济系统时，用来建立「取舍 / 过强策略 / 用模拟找洞」的词汇。

## 1. 资源与反馈环

- 一个经济系统由**资源**（钱、精力、时间、技能等）和它们之间的**转化关系**构成。
- **正反馈环**（钱生钱：投资复利）让强者愈强，容易失衡；**负反馈环**（越有钱消费越贵 / 边际收益递减）能收敛，制造节奏。
- 设计时要问：哪条环在正反馈？会不会导致「前期抢到一点优势就滚雪球碾压」？

## 2. 成本曲线与支配策略（transitive / dominant）

- 若某行动在**所有阶段、所有情形**下都不劣于其它行动，它就是**严格支配策略**——玩家没有真正的选择，经济就「死」了。
- 常见坑：某副业收益随时间线性涨但零风险 → 到中后期无脑最优；「学习」投入产出比永远为负 → 没人点，变成摆设。
- 好的经济应让不同行动在**不同阶段 / 不同风险偏好**下各有最优，形成**非传递（intransitive）**的博弈，而非一条直线碾压。
- 太强要分清改哪一侧。收益本身是「做了就赢」、加价也压不住，是 **overpowered**，必须削收益。只是相对收益太便宜，是 **undercosted**，加成本即可。
- **递增成本**：同一项收益加得越多，下一份越贵。否则玩家会把资源全部砸进当前最强的一项。曲线形状决定节奏偏前、偏后，还是分出早中晚，要和 9 年跨度一起看，不要默认线性。

## 3. 正和 / 零和 / 负和与节奏（pacing）

- **正和**：整体财富随时间增长（投资、复利）——给成就感，但要防通胀式失控。
- **零和 / 负和**：消费、风险事件、机会成本——制造张力与取舍。
- 节奏：早期资源紧、选择重；中期开始分化；后期见胜负。9 年按月推进 = 108 个决策点，注意别让后 60 个月变成无脑重复。

## 4. 造钱 / 销毁与「印钞漏洞」

- 任何"造钱"入口（收益、事件奖励）都要有对应的"销毁 / 成本"来平衡，否则出现**无限印钞**：反复做某组合让净资产无上限增长。
- 这是**封闭经济**：钱只在局内产生和销毁。正和增长（工资、副业、复利）必须有销毁口（消费、维护、失败损失），否则购买力通胀，后期物价和收益一起失真。
- 检查手段：批量模拟里看是否存在「某策略终局净资产远超其它且方差极低」，并抽查**局中净资产路径**和资金进出，而不只看终局。同一行动用得越多，额外一份应越不值钱；否则它会垄断成唯一策略。

## 5. 用模拟找洞（本实验的核心）

把「凭直觉调平衡」换成「跑数据找问题」：

1. 定义 ≥3 种代表性策略（如：稳健工作流 / 激进投资流 / 副业滚动流）。
2. 每种批量跑 ≥100（力争 1000）局，统计三指标：
   - **A 目标达成率**：达成胜利条件的比例。
   - **B 破产 / 硬失败率**：触发失败条件的比例。
   - **C 策略分化**：各策略平均终局净资产；是否存在全面碾压的单一策略。
3. 从数据里**自主发现异常**（某策略严支配 / 某阶段无脑最优 / 某事件极端偏斜 / 某行动无决策价值 / 前 24 月只做 X 后无脑 Y）。
4. 针对洞察改**经济规则**（而非改难度），再跑一遍看是否改善——形成「反馈→分析→决策→修改→再验证」闭环。

## 6. 反 Goodhart 提醒

- 指标一旦成为目标就容易被刷。**不许**靠单纯降低难度、抬高所有收益、取消风险把达成率刷好看。
- 要能解释：经济为什么**形成了有效取舍**（有得必有失），胜利能经**不止一条**合理路线达成，并用数据佐证。
