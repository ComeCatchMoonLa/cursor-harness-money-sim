## 怎么"学结构"而不越界

- 可以借鉴：状态如何建模（净资产 / 精力 / 月份）、回合循环怎么写、进度/存档文件怎么组织、测试怎么摆。
- 不可以：拷贝其游戏规则、数值表、文案、代码文件当作自己的交付。
- 引用思想时在 `PROGRESS.md` 或 `DESIGN_REVIEW.md` 标注"参考了某标本的 X 结构"，保持可追溯与诚实。
