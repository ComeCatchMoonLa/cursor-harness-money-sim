# V6 设计

命题：可选消费要变成取舍。一边是这个月的钱和生活费地板，另一边是接下来几个月时间自主还够不够用。

不加新账。仍用生活水准、时间自主、精力、压力。

- 选了消费槽，时间自主固定加 6，和花了 2000 还是 20000 无关。休息仍只加 2。全职本身仍减 3。多个消费槽不叠加这笔自主。
- 金额仍走原来的减压和人脉。人脉不加码，也不靠它让消费变划算。生活水准最低加 2，3 万以上才再加，封顶 4。不消费的月份，生活水准仍减 1，最低 100。
- 本月生活费按抬高之后的水准扣。月供不变。工资公式不变。
- 预览用引擎算出：相对「这个月不消费」，下个月租房要多付的生活费，以及已购房多付的那一截（不含房租）。
- steady、owner、nest、yolo 只在精力不低于 46、压力不高于 62、时间自主低于 70、现金盖得住两个月账单加最低消费时，把休息槽，或景气不是上涨时的投资槽，换成消费，并且只花 2000。景气好时这个槽仍去博收益。再抬一档水准会让账单超过「水准 100」的 110%，而时间自主已经不低于 36，就停。已购房的账单不含房租、月供不跟着涨，所以同一条 110% 停得更晚。学习槽不被换掉。grind 从不换。

参考 `references/game-design/economic-simulation-notes.md`：消费是负反馈，不该有一档永远最好的花法。
