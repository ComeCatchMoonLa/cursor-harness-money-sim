# V4 设计

命题：自住房是一笔停不下来的现金流出，再加一块不好变现的权益。它不是第二条指数。

- 房价按物价指数浮动，开局 90 万。首付 35%，其余是 240 期月供，月利率 0.4%。消费贷仍是另一套高息，不能拿来替代房贷。
- 租房时，生活费里的 32% 是房租，跟着物价和生活水准涨。买下之后这笔房租不再付，改付月供和大约每年 1.2% 的维修。开局月供加维修高于房租。房租后涨、月供名义不变，所以买房是前紧后松，不是立刻省钱。
- 房子按景气缓慢变动：景气每月约 +0.3%，平淡 +0.1%，收缩 -0.4%。长期跑不赢物价。主动卖掉扣 12% 交易成本再还清贷款。可兑现按这个折扣算，所以刚买下的那个月可兑现会掉一截。
- 现金不够时，先卖没封闭的指数，再折价卖掉房子还贷（只按市价的 78%）。贷款还清前差额仍是你的。封闭的指数不能拿来付首付，也不能替房子挡这次贱卖。
- 同一个月不能又买又卖。买之前要能付清这个月的首付、月供、维修和生活费，不能买下就立刻被自己卖掉。
- 已有的上班策略继续租。新的「安家」策略在不是收缩、工资盖得住月供、卖一点指数就够首付时才买。只上班不学习的极端策略也不买，用来看房租上涨会不会单独构成印钞或破产。

验收：

- 买下之后账面里有房子和房贷，可兑现低于买之前。
- 封闭的指数不能凑首付。
- 自住的生活费低于同一月的租房，同时现金里扣掉月供。
- 主动卖出后房子和房贷都清掉，现金增加额小于房价。
- 现金为负且指数不够时，房子会被折价卖掉还贷。
