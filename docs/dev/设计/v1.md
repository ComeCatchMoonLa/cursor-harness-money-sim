# V1 设计 · 月度时间与资产

命题：玩家能独立玩完约 9 年。每月在就业、时间槽和资金之间取舍。胜利是净资产从 72 万增到 150 万（+78 万）。副业不是第二份时薪。

## 状态

内部单位是元。开局现金 18 万、指数 54 万，净资产 72 万。第 1 到第 108 月可行动。

- 现金、指数仓、副业账面、负债。净资产 = 现金 + 指数 + 副业账面 − 负债。
- 精力、压力、时间自主、职业/经营/投资技能、人脉、生活水准、物价指数。
- 景气：景气 / 平淡 / 收缩。月初可见，月末按约 18% 的概率切走。
- 结局：`won` 净资产 ≥ 150 万；`bankrupt` 卖资产和借到上限后现金仍为负；`burnout` 连续 3 个月行动后精力耗尽且没在同月胜利；`shortfall` 108 月结束仍未达到目标。

## 一个月

玩家提交一份方案，结算顺序固定：

1. 校验失败则本月不发生。
2. 退出副业（主动退出或接受收购）按比例变现，变现比例 < 1。
3. 发工资（用月初技能）。全职占 3 槽，兼职占 2 槽，自由占 0 槽。
4. 执行自由槽：学习、副业、投资、休息、消费。
5. 资金划转：买指数、卖指数（收 0.3%）、投入副业、还债。同月不能又买又卖。
6. 指数收益。有「投资」槽才能把一部分仓位放进高波动风险仓，下月不选投资就自动回到指数。
7. 副业盈亏进现金。
8. 生活费（受生活水准和物价影响）、负债利息。
9. 随机事件。
10. 现金为负时按顺序被迫卖指数、贱卖副业、在上限内借债；仍不够则破产。
11. 精力回复、过劳计数、胜负、物价上涨、景气切换、下月收购报价。

## 行动代价

- 工作：稳定工资，掉精力和自主，加压。月初精力低于 14 不能选全职。
- 学习：学费 + 精力，技能涨幅随当前技能递减，本月不立刻加工资。
- 副业：建造期每槽投入固定本金并推进进度，满 3 槽开业。开业后该槽是亲自经营，不是再领一份工资。不经营又不雇人则收入大减。雇人有刚性成本，规模不够时会亏。
- 投资：占时间槽才能上风险仓。指数本身每月自动计价，不占槽。
- 休息：回精力、降压力，没有收入。
- 消费：花钱降压力并提高人脉（人脉小幅抬工资和需求），同时永久抬高生活水准。不消费则生活水准每月慢慢回落，最低回到基准。

## 风险与可逆

- 退出：建造期可收回约九成；运转中主动退出约五到六成。本月若有收购报价，可以按更高折扣卖掉，也可以不卖。
- 流动性危机中的副业贱卖比主动退出更差。
- 负债月息 1.2%，上限 16 万。
- 事件只做有限额的医疗、裁员（工资改成遣散）、副业受挫（账面缩水）、小额旺季。不发无成本横财。

## 模块

- `money_sim/economy.py`：纯公式。
- `money_sim/engine.py`：校验、结算、记账。
- `money_sim/policies.py` 与 `money_sim/batch.py`：无界面批量模拟。
- `money_sim/server.py` 与 `web/`：界面只展示接口返回的数字。

## 验收用例

1. 新局净资产为 72 万；全职上班并休息一个月后，现金变动等于工资减生活费和其他记账项。
2. 连续只休息会因生活费破产或至少净资产下降，不会印钞。
3. 精力过低时全职方案被拒绝，状态不变。
4. 把现金转入副业或退出副业不会提高净资产。
5. 把指数抬过目标能胜利；负债封顶且现金补不上时破产。结算后的现金、指数、账面、负债与分录一致。
