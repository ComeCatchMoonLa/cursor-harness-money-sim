# V9 设计

命题：到了可以少工作的位置之后，轻职要停得住。状态恢复了不自动回到全职。财富会略慢，时间自主在中段高一截。景气月、还没到位置、合同和外部工资仍继续全职。

- 删掉「状态不低于 58 且时间自主不低于 64 就回到全职」。
- 景气、外部报价、合同没到期、状态低于 40、精力低于 24，仍不改轻职。
- 不拿工资停一整段这一档不做。200 局里多数局面更亏。
- 工资仍是全职的 82%。位置公式不改。胜利线不改。
- steady、grind、yolo、owner、nest 仍不选轻职。

参考 `references/game-design/economic-simulation-notes.md`：少工作不能变成更赚的必选。
