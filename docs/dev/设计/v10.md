# V10 设计

命题：路线有没有实质差别，看五个轴里至少两个，不看谁的终局财富更高。用四条事先写死的条件策略去搜，留下的写明主线和变招。

- 比较轴：达成率、赢局的中位月份、硬失败、第 37 到 72 月的工作强度、同一段的时间自主。没活到这一段的局用实际月份。数字门槛不改，窗口是 200 局之后改的，原因见调研。
- coast：`covered` 为真、位置开着、不是景气、没有合同和外部工资、状态不低于 40、精力不低于 24，才改成不拿工资。否则沿用 ease。
- dwell：ease 的方案上，若 nest 这个月买得起自住，就按它的卖出指数去付首付。买不成就退回 nest 当月的方案。
- after_shop：只有 owner 已经决定把店交给人，才允许改轻职，条件与少工作的位置相同。店还要亲自盯的月份不改。
- craft：第 60 月之前、职业低于 70、当月仍是全职并且有投资槽，把第一个投资槽换成学职业。
- 界面列出这次搜索留下的路线：主线、变招，以及五个数。不替玩家下月做决定。
- 被丢掉的候选和漏洞不放进界面。多种子、自定义开局、教练层不做。

参考 `references/game-design/economic-simulation-notes.md`：不要留下一条在所有情形下都不劣的路线。
