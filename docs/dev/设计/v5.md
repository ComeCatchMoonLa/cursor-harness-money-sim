# V5 设计

命题：外部报价是一份有期限的全职工资，不是永久加薪。接手的那个月没有工资。月供和违约金都不会因此停。

- 全职或兼职、又没有停薪请假、也没有一份还在生效的报价时，月末可能出现下一月的报价。职业新鲜不少于 8 个月时概率 12%，否则 5%。金额由技能、人脉和新鲜度决定，不靠再掷一个运气数字：新鲜 8 个月是现在的全职工资，更高最多加 18%，过时最多减 15%。
- 接受之后，这个月工资是 0，接下来 12 个月的全职工资改成报价。技能不加。职业新鲜度如果低于 8，补到 8，不会比专门学习更长。时间自主减 8。
- 合同还在就必须同时违约，否则拒收。报价只对全职有效。改成兼职或不拿工资，报价作废。到期后工资回到按技能算。
- 还房贷的策略只有在报价高于现在的工资、没有合同、而且现金盖得住这个月没有工资时的生活费和月供，才接受。只上班且不学习的极端策略永远不接。

验收：

- 接受当月工资为 0，技能不变；下一个月的全职工资等于报价。
- 没有报价，或者合同还在又不肯违约，都不能接。
- 新鲜度高的报价高于按技能算的工资，过时的报价更低。
- 只上班的极端策略不接受报价。
