# V16 设计

命题：从一张中途存档，把已经留下的路线打到第 108 月。标准局那五条不重判、不合并、不拆开。第 1 月、72 万那一局的按钮不动。

这一版是指定做的，不靠四问再否掉。

## 打分之前定死

每种路线 200 局。内部种子从 20001 起，第 n 局用 20001+n（n 从 0 到 199）。七条共用这一段。不读玩家的随机数，也不把结果写进 `routes.json`。看到结果之后不改 200，不改 20001，不改下面的差距。

60 局以前会把只在小样本上分开的留下来，这一版不用。1000 局是标准表的种子 1，这一版不重跑那张表。

比较的是七条：留下的 steady、grind、yolo、owner、coast，再加上已经并进一直上班的 nest、ease。变体各打一份，挂在一直上班下面。不回到标准名单。

五个轴和差距仍是：达成 5 个点，达标月 6 个月，硬失败 2 个点，工作强度 0.05，时间自主 3。五个都盖住才从这张短名单拿掉。只差四个轴留下。平均净资产不算。不用 `dominates()`。大于等于才算盖住，不四舍五入。

盖住的方向：达成更高，达标月更早，硬失败更低，工作强度更低，时间自主更高。一边没有赢局，就没有达标月，这一轴不算被盖住。谁盖住谁，按留下的顺序再加变体的顺序，取第一个，不按达成率挑。

短名单按 steady、grind、yolo、owner、coast 排。不按达成率排。达成率最高的不标成最优，也不给这一月填方案。

变体自己被盖住，只从一直上班下面拿掉。一直上班被盖住时，它的卡片不在，先买自住和轻职不升进那五条。

## 窗口

强度和自主只在这张表上改窗口。快照月份小于或等于 72，仍看第 37 到 72 月里实际走到的月份。第 13 月也是这个窗口。已经晚于第 72 月，改看从这个月到第 108 月。窗口里一个月都没活到，用这次实际走过的月份，不记成 0。

标准路线卡片上的第 37 到 72 月不改。`play_once` 不改。

第 108 月没有剩下的月份，写明不打分，不算 200 局。

主线和变招只写从这个月起到第 108 月会走到的段，不用「前 36 个月」。一段里次常见的就业至少占 8%，才写成变招。

## 表上有的和没有的

表上有：月份、现金、指数、封闭金额、负债、房子市价、贷款、职业、经营、投资、状态、合同还剩几个月、物价。

没问的用游戏自己的默认，不接外面的行情。景气是平淡。没有店。精力、压力、时间自主、生活水准、人脉、三种新鲜程度用开局默认。很晚的存档会像刚休息过。不把这些加进表。

封闭金额大于 0 时，还剩的月数按 12。金额是 0 就没有封闭。月供按表上的贷款和现在的等额本息算，不另填。物价套现在的生活费。工资和指数涨跌用现在的常数。

合同剩余只收到 12。技能和状态是 0 到 100。金额是 0 到 10 亿。物价是 1 到 10000。封闭多于指数，或没有房子却有贷款，不打分。
