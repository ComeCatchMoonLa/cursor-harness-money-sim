# V11 设计

命题：已经留下的路线，换一段没定过门槛的种子，还分不分得开。同一轮把三个写死的数各动一档，看名次会不会翻。翻了只在这组常数下成立。两个轴仍分开才继续当作不同路线。分不开就合并。合并也算这一版做完。

跑之前定下的，看到结果不改。

## 留出种子

1000 局，种子 10001 到 11000。调用是 `run_batch(1000, 10001)`，局号加上 10001。不是种子 1。

五轴不改：达成差至少 5 个百分点，达标月至少 6 个月，硬失败至少 2 个百分点，工作强度至少 0.05，时间自主至少 3。强度和自主仍看第 37 到 72 月。没活到这一段的局，用它实际活过的月份。

漏洞线不改：三项同时更好、单月账面跳升超过 55%、终局可兑现超过 600 万。这一版不放进新路线，所以漏洞只记录，不用来留下谁。

## 三个数各一档

方向在跑之前选定。每一档都朝已经写过的代价走一格，不朝「更便宜、更好开」走。

- 月供月利率 `MORTGAGE_RATE_NUM` 从 4 到 5，分母仍是 1000。单位就是这 1。V4 写过不把月供做便宜。开局月供加维修在 3、4、5 这三档都高于房租 4224，所以不靠这个来选方向。往下是做便宜，这一档往上。
- 轻职占全职 `LIGHT_NUM` 从 82 到 81，分母仍是 100。少掉的那一截是代价。81 仍高于兼职的 74，低于全职。
- 位置最多承认的储蓄月数，从 `MONTHS // 3`（36）到 `MONTHS // 4`（27）。V8 已经否过把更远的月份算进去。相邻的一档是除数加 1。

## 名次和合并

名次按达成率从高到低。达成率相同，中位达标月更小的在前。没有赢局的排在后面。留出种子上，一档前后的名次不一样，测试文档写「这组常数下才这样」。

合并只看旧常数的留出种子。按写进路线表的先后：steady、grind、yolo、owner、nest、ease、coast。后一条要和每一条已经留下的都差够两个轴，否则并进轴最少的那条；轴数相同就并进更早的那条。

一档进不进游戏：留出种子上，留下的名单变了，并且种子 1 上 steady 的达成率不低于 61.1%、nest 不低于 64.5%，才留下这三档。名单没变，或者主力达成率掉下这个平台，三档改回去。名单只在一档下变了，写成「这组常数下才这样」，不按一档去合并。

只把主力达成率再压低、没有新的分叉，不算这一版改了规则。

胜利线仍是可兑现 150 万。不给玩家换种子。不搜新策略，不拆指数现金，不对局对照，不加开局旋钮。
