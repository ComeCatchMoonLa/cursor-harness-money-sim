# V7 设计

命题：长期上班会把一个掉得慢的状态磨低。休息补得慢，消费只在偏低时补得回来。低到底，原来的全职就做不了。

- 状态 0 到 100，开局 78。全职 -5，兼职 -2，不拿工资 +2。
- 休息：状态低于 74 时每个休息槽 +3，否则 +0。
- 消费槽：低于 58 时 +8，58 到 74 时 +2，高于 74 时 +0。金额不加状态。学习和经营每个槽再 -1。
- 低于 40 不能全职。合同还在就停薪请假，和精力不够同一条路。不加工资，不改月供，不改店的毛利，不改技能过时。
- steady、nest、owner、yolo 在状态低于 58、精力和现金还允许时，可以把休息或非上涨月的投资槽换成最低消费。状态已经不低于 74、时间自主也已经高，就不再为状态花钱。账单高出开局水准一成的停手线仍在。grind 从不消费。
- 预览给出下月状态，数字来自引擎。

参考 `references/game-design/economic-simulation-notes.md`：负反馈要在强的时候更强，不能变成越花越赚。
