命令：`python3 -m money_sim.sim --games 1000 --seed 1`

终局仍是可兑现。steady 和 nest 会在报价高于现工资、没有合同、交接月付得起生活费和月供时接受。grind 和 owner 不接受。

| yolo | 0% | 100% 破产 | -168049 |
| owner | 9.5% | 0% | 1001467 |
| nest | 86.2% | 0% | 1505717 |

没有碾压策略，没有超过 600 万的终局。40 局里 steady 见到 222 次报价、接受 50 次；grind 见到 249 次、接受 0 次。多出来的随机数让各策略的终局和 V4 不完全相同，没有靠把报价做成永久加薪把达成率做回去。
