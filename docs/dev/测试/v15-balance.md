# V15 平衡

规则在 `docs/dev/设计/v15.md`，跑之前写定。开局景气从平淡改成景气，现金和指数不动。看到下面的数之后，排序规则没有改。五条的先后没有翻，旋钮不放进界面。

排序：达成率高的在前，相同则达标更早。没有赢局的排在后面。只比 steady、grind、yolo、owner、coast。

留出种子 1000 局、10001 到 11000。
