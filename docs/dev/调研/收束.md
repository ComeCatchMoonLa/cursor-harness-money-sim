# 为什么停在 V5

拟真优先。V4 补的是「要不要把首付锁进自住房」。V5 补的是「有人开价时，接不接得起这个月没有工资」。这两件是九年账里原先不存在、又会改变现实决策的两块。

1000 局里，买房比一直租略好一点，但刚买下可兑现先掉约 10 万，不是印钞。跳槽被接受的次数远少于出现的次数，只上班且不学习的路径仍然大多到不了目标。没有一条策略三项同时最好。

再往下的候选，边际效用已经低了：

- 个税和缴费分档。验收明确不做税务精算。一条平均税率教不会新的取舍，分档又是另一套账。
- 第二套房。住房会从一笔现金流决策变成买卖资产，和已经有的指数、店叠在一起。
- 家属和随机账单。支出可以再加，玩家没有对应的新选择。
- 让店主机器人更会退出。退出按钮 V1 就有，那是策略程序的事，不是再加一个系统。

所以停在这里。
