# V5 调研

住房补上之后，就业这边仍只有两条出路：被裁，或者花钱违约换自由。现实里更常见的是有人开一个价。接不接，要看合同还在不在、这个月有没有工资、月供还在不在。

报价如果永久加在工资上，跳槽会变成加薪按钮。所以报价只维持十二个月，而且接手的那个月没有工资。合同没到期还要另付两个月违约金。技能不加。新鲜度最多补到「正在做」的水平，补不到专门去学的那么长。

过了这一版，剩下的候选是个税分档、第二套房、家属。验收写明不做税务精算。第二套房会把住房从「一笔决策」做成地产经营。家属主要是随机支出，玩家没有对应的选择。这三件的边际都低于已经做完的住房和跳槽。V5 的数据如果没有露出同样大的洞，就停。
