# V3 调研

V2 把可兑现、任期和封闭仓做实了。技能一旦学上去就永远有效，收缩期的裁员、店面受挫和指数下跌仍是分开掷骰，时间自主几乎只改副业几个点收入。

结果是：前两年把职业学过线之后，后面可以不再学习；景气差的时候三套资产不会在同一个月一起挨打；签了长约的人，休息变差只跟「有没有合同」有关，跟你还剩多少时间自主无关。

参考 `references/game-design/economic-simulation-notes.md`：不同阶段不该有同一条支配行动，正反馈要有对应的销毁。本版用技能保鲜期做后期的销毁，用收缩月把已经存在的店、指数和身体绑成一次冲击，用时间自主去改 V2 合同休息的回血。不新开一条收入。
