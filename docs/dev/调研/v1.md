# V1 调研笔记

只记录会影响本版施工的结论。标本只参考了「状态 + 月循环 + 测试分开」的组织方式，没有搬规则或代码。

## 结论

- 资源至少要有现金、风险资产、副业账面、精力。只做现金会把所有行动收成「加减钱」。参考 `references/game-design/economic-simulation-notes.md` 的资源与反馈环。
- 正反馈（指数复利、副业留存）必须配销毁：生活费通胀、卖出摩擦、退出打折、受挫缩账面、负债利息。否则批量模拟会出现低方差的印钞策略。
- 严格支配是失败信号：若「永远全职 + 余钱买指数」在达成率、硬失败率、平均净资产上同时最好，经济是死的。V1 就要有能打出这种对照的极端策略，而不是等 V3。
- 副业若按小时发工资，就会变成第二份工作。本版把副业做成要投入本金、边际递减、不照看会萎缩、可以雇人但有刚性成本、退出只能打折变现的资产。
- 9 年 108 步不能只靠开局选一次职业。景气每局会切换，收购报价在副业运转后随机出现，所以后半程仍要决定仓位和卖不卖。
- 技术栈用 Python 标准库：引擎可单测，`python3 -m money_sim.sim` 能跑上千局，界面用本地网页，不引入前端构建。`references/examples/example-project.md` 里的标本只用来对照目录，不复制。

## 本版明确不做

劳动合同锁定期、封闭式理财、技能过时、跨市场连带危机。这些是后续大版本的厚度，不塞进 V1。
