# V11 筛选

上一节把店上的走法和穷开局停掉。那一节不删。这一版不从那里再挑一条。

重新打开的五条里，这一版只做第 1 条：用没参与定门槛的种子，重跑已经留下的路线，并在同一轮把三个写死的数各动一档。不是给玩家换种子，也不是只交一份报告。

第 2 到第 5 条为什么留下一版，写在 `docs/dev/调研/候选池.md` 的「这一版选第 1 条」。

参考 `references/game-design/economic-simulation-notes.md`：一种做法若在所有情形下都不劣于其它做法，选择就没了。这里先问的是另一段种子上，两条路线还是不是两条。只在定门槛的那一段种子上分开，不算已经分开。

## 结果

留出种子上，nest 对 steady 只差达标时间，ease 对 steady 只差时间自主。两条都并进 steady。coast 仍和留下的每一条差够两个轴。月利率、轻职比例、36 个月的一档让名次从 nest 开头翻成 ease 开头，并把种子 1 上 nest 的达成率从 64.5% 压到 54.8%。按设计，这组常数不进游戏。数字在 `docs/dev/测试/v11-balance.md`。
