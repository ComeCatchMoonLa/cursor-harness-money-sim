# V4 调研

到 V3 为止，玩家能练的是：时间槽、技能会过时、纸面财富不能直接当赢、合同和封闭仓不能当月反悔。开局 72 万里有 54 万指数。现实里这笔钱最常被拿去问的那件事，游戏里不存在：要不要把首付锁进一套自住房。

生活费是一个数。它不区分房租和饭钱，所以租和买没有差别，月供这种停不下来的现金流出也不存在。指数可以下个月卖掉，房子不能。这是现在最大的一块失真，也是最值得先补的一块：一个决定，改的是现金流弹性和可兑现，不是再加一条收入。

先不做的：

- 个税和五险一金的分档。验收写明不做税务精算。等住房和跳槽都在，一条税率的边际已经不大。
- 第二套、装修、多城市。那是经营游戏，不是这一笔决策。
- 把胜利条件改成扣除通胀。验收写的是净资产相对开局大约加 78 万，名义目标不动。房价和生活费继续跟着物价指数走，用来表现房租会涨、月供不会。

下一版如果还值得做，是外部工作报价：现在只有被裁和花钱违约，没有「有人出更高的价，但你得解约，而且房子的月供还在」。再往后边际效用就低了。
